# PDR Browser

> Explore a Rootbeer Package Distribution Repository (PDR) with a web UI.

The PDR browser is a single-page application built with Solid.js that can fetch
a package distribution repository and allow users to search, filter, and view
package details in an intuitive web interface. This project is used by the
[official Rootbeer PDR](https://search.rbpkg.com).

# Installation & Self-hosting

You don't need to host this right now, unless you host a PDR. But it's early
days and none of this is built for self-hosting yet. Figure it out by reading
the source code of the Rootbeer PDR.
